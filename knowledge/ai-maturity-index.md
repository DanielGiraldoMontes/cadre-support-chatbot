# AI Maturity Index

## Summary

The AI Maturity Index is Cadre AI's diagnostic tool for scoring how far along a business is in its AI adoption journey.

## Key facts

- It scores a business across an eight-pillar framework covering the different dimensions of AI transformation (strategy, tooling, data/security, team readiness, and related areas).
- The output is a grade in each pillar, with clear explanations of what the grade means.
- Alongside the grades, it gives actionable insight into how to improve and move further along in the company's AI journey.
- It is positioned as a starting point for a conversation with Cadre, not a fully automated self-serve report — the verified path to get one is to request it through Cadre's contact channel ("Get Your AI Maturity Index").

## How the chatbot should handle this

- If asked what the AI Maturity Index is → answer using the summary above.
- If asked "how do I get scored" → the verified next step is directing them to request it via Cadre's contact page / talking to an AI strategist (see `getting-started.md`). Do not invent a self-serve link, quiz, or instant scoring tool inside this chatbot unless one is actually built.
- If this project builds its own lightweight "mini-assessment" widget (P2, optional — see `PLAN.md`), it must be clearly labeled as an informal, indicative preview, not Cadre's official Index or methodology.

## If asked something not covered here

The exact eight pillars, scoring methodology, or benchmark data are not public — escalate rather than inventing pillar names or scoring criteria.
